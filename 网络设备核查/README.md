# 网络设备核查（独立版）

交换机、防火墙等**网络设备**的核查脚本独立副本，覆盖《配置核查作业指导书》v2.2 第 5 章网络安全 **5.1–5.23 共 23 项**。设备是独立硬件，无法在被测机上跑脚本，因此采用「**采集-解析**」两步模式，这一份可以单独交给网络/运维组使用。

> 本目录是从 `..\win\`、`..\kylin\` **整份复制**出来的，原目录未做任何改动；两份脚本逐字节一致（见文末"同源与更新"）。要改动网络核查逻辑，请仍改原目录，再把新版本整份复制过来。

## 快速开始

**Windows 管理机**（系统自带 PowerShell，无需安装任何软件）：

```bat
双击 run.bat            :: 一键：未采集时生成采集清单，已采集时直接出报告
run.bat init            :: 第 1 步：生成采集工作区与三厂商命令清单
run.bat check           :: 第 2 步：解析回显、生成报告
run.bat help            :: 查看用法
```

`check_network.bat init / check` 是等价入口（与主包 `win\` 同名同源），习惯原命令的可用它。

**麒麟 / Linux 机器**（纯 Bash，需要 `zip` 命令才能出 .xlsx，缺失时自动降级为 .html/.xls）：

```bash
bash check_network.sh init     # 第 1 步：生成采集工作区
bash check_network.sh check    # 第 2 步：解析回显、生成报告
```

两个平台的**采集文件通用、判定逻辑一致**：在哪台机器采集、在哪台机器出报告都行。

## 工作流程

1. **生成采集工作区**（`init`）
   在 `output/netdev/` 下生成操作说明与三厂商命令清单模板：
   - `采集说明.txt` —— 操作指引
   - `采集命令清单-华为华三.txt` —— 16 条命令模板
   - `采集命令清单-锐捷.txt` —— 10 条命令模板

2. **登录设备采集回显**
   运维陪同登录每台设备，先在设备上执行 `screen-length 0 temporary` 取消分页，然后按清单逐条执行命令，把回显**直接粘贴**进对应的 `设备名.txt`：

   ```
   output/netdev/核心交换机-华为.txt
   output/netdev/汇聚交换机-华三.txt
   output/netdev/出口防火墙.txt
   ```

   每台设备一个 txt，模板里 `########## CMD: <命令> ##########` 分隔行不要删除——脚本靠它切分命令段。设备回显编码为 UTF-8 或 GBK 都能自动识别。

3. **解析回显、生成报告**（`check`）
   一个 txt 也没采集时脚本会明确提示，不会生成空报告。

## 输出

报告带时间戳输出到本目录 `output/`：

| 运行平台 | 产物 | 说明 |
|---|---|---|
| Windows 管理机 | `配置核查报告_网络设备_日期时间.html`、`.xls` | 交互版 + 表格版 |
| 麒麟 / Linux | `.html`、`.xls`、`.xlsx` | 多一份 .xlsx；机器上没有 `zip` 命令时自动降级为 .html/.xls |

HTML 是交互版（指标卡、搜索、筛选），推荐归档；.xls/.xlsx 用 Excel/WPS 直接打开。每条结论附对应指导书章节出处，不合规项给出整改建议列。

同一批设备回显在两个平台各跑一遍，23 项判定完全一致（已实测 23/23）。

## 23 项判定能力

| 类别 | 项数 | 检查项 |
|------|------|--------|
| 自动判定 | 12 | 5.3–5.8、5.10、5.11、5.16、5.18、5.19、5.23（VLAN/路由/SSH/ACL/802.1x/端口隔离/组播/双机热备/端口闲置率等设备命令回显类） |
| 部分信号 | 5 | 5.9 异构部署、5.12/5.17 传输加密层次、5.14 等级隔离、5.22 存储网分离（脚本提取型号/IKE SA/会话表/VLAN 划分，结论需与台账比对） |
| 需人工 | 6 | 5.1、5.2、5.13、5.15、5.20、5.21（审批记录、方案文档、平台界面类） |

与指导书第 5 章、核查表第 14 列标注一一对应。

## 并入总汇总（可选）

把 `output/netdev/` 整个目录拷到主包对应位置，再跑主包的一键脚本，网络设备核查会作为「网络设备」组件自动并入汇总：

```bash
# 麒麟机
cp -r output/netdev ../kylin/output/ && sudo bash ../kylin/run_all.sh
```

```bat
rem Windows 管理机
xcopy /e /i /y output\netdev ..\win\output\netdev\ && ..\win\run_all.bat
```

汇总时同一组件只取最新一份报告，重复运行不会叠加。

## 同源与更新

本目录脚本与主包原文件**逐字节一致**（MD5 前 12 位）：

| 本目录文件 | 来源 | MD5 前 12 位 |
|---|---|---|
| `check_network.ps1` | `..\win\check_network.ps1` | `0e2646ca7f23` |
| `check_network.bat` | `..\win\check_network.bat` | `9c0200a1083d` |
| `check_network.sh` | `..\kylin\check_network.sh` | `e3ad4610002a` |
| `lib_xlsx.sh` | `..\kylin\lib_xlsx.sh` | `cbb5f7bd9683` |

更新方式：在原目录改好并验证后，把上述文件**整份复制**到本目录（`check_network.sh` 少了同目录的 `lib_xlsx.sh` 就不会生成 .xlsx）。校验命令：

```bash
cmp -s check_network.sh ../kylin/check_network.sh && echo 一致
```
