## 3.1 集中存储的涉密数据应采取加密保护措施

**【检查方法】**（指导书 v2.0.0）
- Windows：`manage-bde -status` 查BitLocker加密状态；`cipher /c <目录>` 查文件级加密
- 中标麒麟/银河麒麟：`cryptsetup` + `lsblk -o NAME,FSTYPE | grep crypto_LUKS` 查LUKS加密分区

**【判定标准】**
- pass：检测到LUKS/BitLocker加密分区
- fail：明确未加密
- manual：未安装cryptsetup或无法确定，需人工确认

**【工具实现】** `check_kylin.sh` → `check_3_1_encryption()`；Windows → `Check_3_1_Encryption`

**【实测证据】**（2026-08-08 沙盒 Git Bash）
- 判定：需人工核查
- 详情：未检测到cryptsetup，请人工确认磁盘加密（LUKS）部署情况。

**【结论】** 沙盒环境无cryptsetup，判manual/na；真实麒麟机检测到LUKS则判pass。
